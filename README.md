## Website

Visit the site at: [https://maykolmedrano.github.io](https://maykolmedrano.github.io)

## Built With

- [Quarto](https://quarto.org/) - Open-source scientific and technical publishing system
- [Bootstrap Sandstone Theme](https://bootswatch.com/sandstone/)
- Custom CSS and typography (Manrope font)

## Local Development

```bash
# Install Quarto: https://quarto.org/docs/get-started/

# Preview the site
quarto preview

# Render the site
quarto render
```
